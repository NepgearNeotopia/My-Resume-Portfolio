PROJECT 01

ระบบบริหารจัดการห้องปฏิบัติการ และการยืม-คืนอุปกรณ์ผ่าน Web Application

วิชา: SELECTED TOPICS IN ELECTRONICS AND COMPUTER ENGINEERING I

โปรเจกต์สำหรับพัฒนาระบบบริหารจัดการ ห้องปฏิบัติการและระบบยืม-คืนอุปกรณ์ ผ่าน Web Application

ความสามารถของระบบ

  • ระบบ Login และกำหนดสิทธิ์ผู้ใช้งาน Administrator / อาจารย์ / นักศึกษา
  • ระบบจัดการข้อมูลห้องปฏิบัติการ
  • ระบบจัดการข้อมูลอุปกรณ์
  • ระบบจองห้องปฏิบัติการ พร้อมตรวจสอบห้องว่าง
  • ระบบยืม-คืนอุปกรณ์
  • ระบบติดตามสถานะอุปกรณ์
  • ระบบแจ้งเตือนอุปกรณ์เกินกำหนดคืน
  • Dashboard แสดงข้อมูลสรุปและสถิติ
  • ระบบรายงานและส่งออกข้อมูล PDF หรือ Excel

เทคโนโลยีที่ใช้: Web Application

สถานะ: กำลังดำเนินการ

PROJECT 02

Mini Project: Linear Control

วิชา: ระบบควบคุมเชิงเส้น

ศึกษาความเชื่อมโยงระหว่างระบบจริง แบบจำลอง และพฤติกรรมของระบบ โดยเน้นการทำความเข้าใจเชิงแนวคิด และไม่เน้นการคำนวณเชิงลึก

สิ่งที่ศึกษา:

  • ลำดับของระบบ (Order)
  • แนวโน้มการตอบสนองของระบบ เช่น เร็วหรือช้า
  • การเกิด Overshoot หรือ Oscillation
  • ผลของค่าพารามิเตอร์ต่อพฤติกรรมของระบบ
  • Steady-state Error ในเชิงแนวคิด

สถานะ: เสร็จสิ้น

PROJECT 03

วงจรกรองกำจัดแถบความถี่ (Band-reject Filter; BRF)

รายวิชา: อุปกรณ์และการออกแบบวงจรอิเล็กทรอนิกส์

โครงงานศึกษาและออกแบบวงจร Band-reject Filter (BRF) ซึ่งทำหน้าที่ลดทอนสัญญาณในช่วงความถี่ที่ไม่ต้องการ ขณะที่ปล่อยให้ความถี่อื่นผ่านไปได้

สิ่งที่ทำในโครงงาน:

  • ศึกษาทฤษฎีเกี่ยวกับวงจร Band-reject Filter
  • ศึกษาการทำงานของ IC 741
  • คำนวณค่าความถี่ของวงจร
  • ออกแบบลายวงจรด้วยโปรแกรม KiCad
  • สร้างวงจร PCB
  • จำลองผลการทดลอง
  • ทดลองวัดค่า Vout ที่ความถี่ต่าง ๆ

ผลการทดลอง: วงจรสามารถลดทอนสัญญาณบริเวณความถี่ที่ต้องการได้ โดยจากการทดลองพบว่า Vout ลดลงมากที่สุดบริเวณ 2.7 kHz ซึ่งวัดได้ประมาณ 360 mV

เทคโนโลยีและอุปกรณ์: IC 741, Resistor, Capacitor, PCB และ KiCad

สถานะ: เสร็จสิ้น
